A program that writes one image summing up the world news of Thursday 19 November 2026. `main.py` (Python 3.13, standard library only) copies the front page in this repository to `/output/entry.png`. The image itself is `entry.png` (1024x1024).

Entry for the [make.fun news image bounty](https://make.fun/bounty/news-image-20261119).

## How to run

```sh
python3 main.py
```

This writes the image to `/output/entry.png`, or to `$MAKEFUN_OUTPUT_DIR/entry.png` when `MAKEFUN_OUTPUT_DIR` is set.

## What the image shows

Six stories from 19 November 2026:

- Trump, Xi, and Putin meet at a Shenzhen summit
- Anthropic's $81B IPO
- The Crimean Bridge attack
- The GTA VI launch
- Voyager 1 one light-day out
- Four nations urging Gaza aid access
